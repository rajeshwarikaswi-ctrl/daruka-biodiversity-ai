# Darukaa.Earth - AI Biodiversity Intelligence Chatbot

An evidence-grounded AI system that reasons about biodiversity, soil, water, and
climate like an environmental scientist - not a chatbot.

Built for the **Darukaa.Earth AI Biodiversity Intelligence Chatbot Challenge**.

## What makes it different

- Deterministic reasoning + RAG (not free-form LLM generation)
- Every recommendation links >=3 environmental variables (soil/water/biodiversity/climate)
- Every recommendation is backed by FAO/IPCC/IPBES/peer-reviewed references
- Works fully without any LLM (LLM is optional, only for rephrasing)
